# Multi-Step Form

A responsive multi-step form built with React. This project demonstrates how to collect user input across several steps, validate data, and manage form state efficiently.

## Features

- Multi-step navigation (Next, Back)
- Form validation at each step
- Progress indicator
- Responsive design
- Easy customization

## Getting Started

### Prerequisites

- Node.js (v14+)
- pnpm, npm or yarn

### Installation

```bash
git clone https://github.com/chamumutezva/multi-step-form.git
cd multi-step-form
pnpm add
```

### Running the App

```bash
pnpm run dev
```

The app will be available at `http://localhost:3000`.
